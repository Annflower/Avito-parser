Parser

Парсер объявлений о продаже квартир с сайта Avito (на примере Новосибирска).  
Инструмент предназначен для автоматизированного сбора данных, фильтрации и экспорта в структурированный формат в рамках задач аналитики, мониторинга рынка недвижимости или учебных проектов.  
Парсер позволяет получать актуальные объявления без необходимости ручного копирования.

 
 Функциональные возможности
- Автоматическая загрузка страниц через браузер (Selenium WebDriver)
- Извлечение ключевых полей: цена, адрес, заголовок, ссылка
- Сохранение результатов в формате CSV
- Настраиваемые параметры поиска (город, минимальная цена)


 Технологический стек:
- Python 3.14+
- Selenium WebDriver
- BeautifulSoup4
- WebDriver Manager
- Requests
